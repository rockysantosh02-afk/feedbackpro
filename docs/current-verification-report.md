## 2. Critical Items Requiring Remediation in Phase 2

1. **Alembic Baseline Migration**:
   * Create `alembic/versions/` directory.
   * Generate an autogenerated initial revision script capturing all 19 entities.
   * Test `alembic upgrade head` on a fresh test database from scratch to verify constraints, indexes, and FK cascades.

2. **Decouple In-Process Background Task from Worker**:
   * Add `INLINE_AUDIT_EXECUTION: bool = False` configuration setting.
   * Ensure API only creates the `AuditJob` with `status='pending'` by default, allowing the standalone `AuditWorkerDaemon` to lease and process it independently.

3. **Database Concurrency in Job Queue**:
   * Enhance `DatabaseJobQueue.lease_next_job` to support `with_for_update(skip_locked=True)` when connected to PostgreSQL to eliminate race conditions between multiple concurrent worker instances.

4. **Health Check Return Format**:
   * Ensure `GET /health` explicitly includes `"status": "ok"` alongside detailed service diagnostics.

5. **Docker & Render Packaging**:
   * Create `frontend/Dockerfile` for multi-stage Vite + Nginx build.
   * Update `render.yaml` to specify `rootDir: backend` and `rootDir: frontend`.
   * Update root `package.json` scripts to remove stale Node backend references.

6. **Live Runtime & Security Verification**:
   * Spin up actual FastAPI server and worker process.
   * Execute real live HTTP tests: 2-user IDOR, live website audit, live redirect SSRF, prompt injection disarming, public feedback submission, correlation, and CSV formula escaping validation.
