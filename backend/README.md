# FeedbackPro Backend API & Worker Service

FastAPI-powered security audit, analytics, and participant feedback platform.

## Features
- **Zero-Trust Security Auditor**: SSRF protection, CSP analysis, HTTPS header checks.
- **Firebase Authentication**: Seamless Google OAuth and JWT-based session management.
- **AI-Powered Form & Report Generation**: Automatic feedback questionnaires and health audits.
- **Transactional Queue & PostgreSQL Storage**: Reliable background audits and metrics.
